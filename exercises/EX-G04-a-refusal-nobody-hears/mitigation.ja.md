# EX-G04 の対策 — 何を、なぜ拒否したかを、パスが開いているうちに言う

## 変更点

`CUBERANGE_OBC_VERIFY_REPORTS=1`。拒否に、テレコマンド 1 通分の返事を付ける。

```c
static void send_acceptance_failure(uint16_t dest_id, const uint8_t *failed_packet,
				    uint8_t failure_code)
{
	...
	sec[1] = 1;                       /* サービス 1、要求検証 */
	sec[2] = 2;                       /* サブタイプ 2、受理失敗 */
	memcpy(app, failed_packet, 4);    /* Request ID をそのまま */
	app[4] = failure_code;
}
```

ECSS-E-ST-70-41C のサービス 1 である。Request ID は拒否されたパケット**自身の先頭 4 オクテット**——
バージョン、型、副ヘッダフラグ、APID、続いて順序フラグと連番。
何も発明せず、何も記憶しない。地上は既に手元にある指令と突き合わせる。
`src/cuberange/proto/pus.py` に `request_id()` があり、それが符号化済みパケットの `raw[0..4]` と
等しいことを、信じるのではなくテストで検査している。

報告は、拒否された指令を送った局宛に出す。すべての局がすべての下りを聞くチャンネルでは、
**もう一方の運用者に「あなたの指令は失敗した」と伝えることは、パスを混乱させる新しい方法**になるからである。

## 地上側で何が変わったか、そしてそれが些細でない理由

`GroundStation.ping()` は送信前にリンクを排出し、**排出したものを捨てていた**。
PUS 1,2 は PUS 8 への返事であり、その 2 つの間で誰もポーリングしていなかった。
つまり宇宙機が「地上に知らせるために」送った報告を、次の ping が捨てていた。
`collect()` は捨てずに分類する。**証拠を落とす排出は排出ではない**。
証拠について教えるために作られたレンジでは、これは 1 行のコード以上の意味がある。

## これが解決しないこと

対策を過大に売るのは、対策が無いより悪い。はっきり書く。

- **報告も認証されていない。** 送信できる者は誰でも PUS 1,2 を偽造でき、
  実行された指令を「拒否された」と、あるいはその逆を運用者に伝えられる。
  これで 4 演習連続で同じ終わり方だが、それはこの演習集の**主題**であって見落としではない。
- **覆っているのは 1 種類の拒否だけである。** 権限検査は報告するが、PUS 8 の長さ検査は報告せず、
  未知の機能も報告せず、COMM の再送拒否——EX-G03 の主題そのもの——も報告しない。
  COMM はパケット層の下にいて、規格の答えは TM フレームの運用制御欄に載る CLCW であり、
  それはこの変更より大きい。
- **成功報告が無い。** ECSS の 1,1 と 1,7 は存在し、何も受け取らない運用者は依然として
  「受理されて動いている」と「失われた」を区別できない。この演習が曖昧さを解消したのは片方向だけで、
  **拒否は大きな声になり、成功はまだ沈黙している**。
- **パスとの対応付けが無い。** 報告は要求を名指しするが、時刻も局の文脈も持たず、宇宙機の時計は起動時間である。
  事後に一連の出来事を再構成するには、依然として地上の記録が要る。
- **そして傾向を検知しない。** 拒否 1 回は 1 回報告され、100 回は 100 回報告される。
  **ある送信元からの指令が 10 分間すべて拒否され続けている**ことに機上の誰も気づかない。
  そしてそれこそが、EX-G03 の障害を名指ししたはずの観測である。

## 実機設計なら何をするか

検証サービスを完全に実装する。受理の 1,1 と 1,2、完了の 1,7 と 1,8、そして
どれを送るかはテレコマンド自身の副ヘッダにある確認応答フラグが決める——
このコーデックが既に運んでいて誰も読んでいない `ack` 欄である。
「自分のどの指令が効いたのか」という問いへの規格の答えは、サブタイプ 1 つではなく 4 つである。

その下にイベント報告（サービス 5）を置く。単発の拒否では表現できない条件のためである——
繰り返し拒否されている送信元、出現した仮想チャンネル、跳んだカウンタ。
さらにその下に認証を置く。報告が「誰が送ったか」について意味を持つようにするためであり、
このレンジの演習はすべて、同じ理由でそこに行き着く。
