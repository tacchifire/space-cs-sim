# Hardware library

Pinned KiCad symbols and footprints for the testbed boards.

## Rules

- Vendor-supplied symbols and footprints are preferred over hand-drawn ones.
- Anything generated or redrawn is checked against the part's datasheet
  before it is used in a schematic.
- A part is pinned here only once its orderable part number is fixed; the
  pinning records the exact variant, not a family name.

## Status

- Empty. Parts are pinned during phase 4 (KiCad design), after the phase 1
  specification freeze fixes the part list.
