# 攻撃セグメント（タップ基板）

攻撃されることを前提にした、CAN 幹線の唯一の区間。バックプレーンのコネクタ
分断点に差さり、物理層の演習が起きる場所を、定義され・検査可能で・取り外し
可能なものにする。タップ基板を外して通常のスルー基板を差せば、ベンチは再び
クリーンなベンチに戻る。

## 骨格仕様

| 項目 | 方向性 |
| --- | --- |
| 形態 | 幹線の1区間に差さるセグメント。通常のスルー基板とピンコンパチブル |
| パッシブタップ | 外部アナライザや CAN アダプタ向けの高インピーダンス受信点 |
| 介在 | 区間の両半分の間にデバイスを挿入できる分断点 |
| 故障注入 | 名前のある故障のためのスイッチ: 終端除去、終端二重化、CANH/CANL 短絡、ライン入替 |
| 可視性 | 全ての故障はラベル付きスイッチで選択する。緩い配線で故障を作らない |

## 設計要件

- タップ基板を外してスルー基板を差せば、幹線は終端を含めて仕様どおりの
  状態に戻ること。
- パッシブタップは、観測対象の振る舞いを変えるほどバスを負荷してはなら
  ない。その入力インピーダンスは仕様凍結の一部とする。
- バスを損傷させる公認の方法は故障注入スイッチのみ。実行中の切断・屈曲・
  抜去でベンチを故障状態にしない。
