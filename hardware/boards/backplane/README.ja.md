# バックプレーン

4ノードが差さる基板。EPS の単点受電から各ノードへの電源と、ノード間の CAN
幹線を担う。

## 骨格仕様

| 項目 | 方向性 |
| --- | --- |
| 受電 | EPS の位置に USB-C 5 V、単点 |
| 配電 | ノード別フィード。各々にスイッチと電流計測 |
| 保護 | 受電点での電流制限と逆極性保護 |
| CAN 幹線 | 4つのノード位置を巡る1対の差動ペア |
| 終端 | 幹線の両端のみ、切替可能 |
| 攻撃区間 | 幹線の1区間はコネクタで分断し、タップ基板が差さる |

## 設計要件

- 1つのノードを、他のノードの電源やバスに影響を与えずに、電源断・計測・
  取り外しできること。
- 終端は幹線の両端にのみ存在する。設定ミスでノードが3つ目の終端を追加でき
  てはならない。終端破壊はタップ基板の故障注入機能であり、バックプレーンの
  機能ではない。
- v1 で外部電源がベンチに入る場所は受電点のみ。電池はない。
- 受電電圧、各ノードのフィード、CANH/CANL のテストポイントを備える。

## 未決事項

- ノードコネクタとスロット形状は未決。
- 電流計測の方式（シャントとアンプか、統合モニタか）は未決。演習が必要と
  する精度はフェーズ1で固定する。
